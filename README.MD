6. MongoDB
7. Monogoose

## Description
It is an incident tracking application designed to help users record, manage security incidents.

## User stories
1. As a user, I want to create an account.
2. As a user, I want to sign in to my account so I can see the security incidents.
3. As a user, I want to create a new incident so I can alert the employees. 
4. As a user, I want to view all incidents so I can keep track of reported incidents.
5. As a user, I want to view all the details such as severity and status.
6. As a user, I want to edit incidents that i created so I can keep it updated.
7. As a user, I want to delete incidents that i created when they are no longer needed.
8. As a user, I want to be able to go back to the incidents from the database if i accidently deleted it.
9. As a user, I want to add the affected systems so I can know what are the impacted devices.
10. As a user, I want to add investigation notes to document the process.
11. As a user, I want to export the incidents as a PDF to share it as a report.
